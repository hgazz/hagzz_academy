# إصلاحات مسار تشغيل الشركاء — ١٩ أكتوبر ٢٠٢٦

- تُحدد الأكاديمية من `partner_users.academy_id`، بما يشمل المجموعات والحضور والمنافسات وتقارير الطلاب والاستعلامات والتصديرات التي كانت تستخدم معرّف حساب الموظف. يبقى تسجيل منفّذ العملية مرتبطًا بحساب الموظف.
- تتحقق أكواد العضوية الموقعة من HMAC، وتُرفض الأكواد الموقعة المحرفة دون تحويلها إلى بحث بمعرّف قديم أو هاتف. يبقى الإدخال اليدوي للأكواد القديمة والمعرّفات والهواتف محصورًا في الأكاديمية المالكة.
- تُحسب حالة سداد الاشتراك من التحصيل الفعلي والقيمة الصافية بعد الخصم عند الحفظ، ولا يمكن تغييرها يدويًا من النموذج. يدعم هذا الإنشاء وتعديل القيمة وتسجيل الدفعات وتطبيق الخصم وإلغاؤه. الاشتراك المجاني لا يستلزم تسجيل دفعة صورية.
- ترحيل `2026_10_19_000001_reconcile_student_subscription_payment_statuses` يصحح الحالات التاريخية فقط، دون إنشاء أو تعديل دفعات أو تغيير تواريخ تعديل الاشتراكات. لا يمكن أن تعيد عملية rollback الوسوم الخاطئة السابقة.
- تعرض فاتورة الاشتراك كل الدفعات، وطريقة كل دفعة ومرجعها وقيمتها وتاريخها، بترتيب التاريخ ثم المعرّف. لم يعد اختيار دفعة واحدة يخفي التحصيل بطرق مختلفة.
- يقرأ معالج التحميل طريقة إرسال النموذج من HTML، لتجنب تعارض عنصر باسم `method`. يتغير رابط السكربت بتغير الملف لمنع استخدام النسخة المخزنة القديمة.

## التحقق

نجحت مجموعة PHPUnit كاملة: ٣٥ اختبارًا و٣٨٤ تحققًا، بقاعدة SQLite معزولة لا تستخدم بيانات العملاء. تشمل الاختبارات تعارض معرّف المستخدم مع أكاديمية أخرى، ومنع العرض والكتابة والتحصيل العابر للأكاديميات، والتوقيع المحرف، والسداد بعد الخصم، وإصلاح البيانات التاريخية دون تغيير سجل الدفعات، وتفاصيل الدفعات في الفاتورة.

وأُعيدت حالات الفيديو على MariaDB المحلية: الحساب الثاني يرى المجموعة وكشف الحضور، والكود المحرف مرفوض، والتحصيل ٤٠٠ لاشتراك قيمته ٥٠٠ وخصمه ١٠٠ يعطي المتبقي صفرًا والحالة «مدفوع». فحص المتصفح أكد عدم ظهور خطأ JavaScript في نموذج التحصيل، وعرض الدفعتين في قوالب A4 وA5 وPOS.

## تطبيق الإصلاح على السيرفر

يلزم تشغيل الترحيل بعد تحديث الكود وإعادة بناء حاوية الأكاديمية. من كونسول السيرفر المتصل بحساب النشر:

```bash
cd /home/hagzz/hagzz/apps/hagzz_academy &&
git pull --ff-only origin master &&
cd /home/hagzz/hagzz/infra &&
docker compose build academy &&
docker compose up -d --no-deps academy &&
docker exec -w /var/www/html hagzz-academy-1 sh -c 'php artisan migrate --force && php artisan route:cache && php artisan config:cache && php artisan view:clear'
```

هذه نتائج تحقق محلي، ولا تثبت نشر النسخة على سيرفر الإنتاج. الفيديو السابق نسخة مراجعة؛ يحتاج تحديث لقطات حالة السداد والفاتورة بعد اعتماد الإصلاحات.
